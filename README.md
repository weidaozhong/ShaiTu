# 晒图 · ShaiTu

把截图挂在桌面晾衣绳上，随手复制、查看和拖动排序。支持 Snipaste 钉图联动，也能使用 Windows 自带的截图工具。

**Windows 10 / 11 · .NET Framework 4.8 · 便携版，无需安装**

![晒图界面：三张示例图片由夹子挂在桌面晾衣绳上](./assets/readme/interface.png)

*程序实际渲染的界面，使用示例图片。*

## 开始使用

1. [下载最新便携版 ZIP](https://github.com/weidaozhong/ShaiTu/releases/latest)，完整解压到固定文件夹。
2. 运行 `ShaiTu.exe`，保留同目录的 `ShaiTu.exe.config`。程序在任务栏托盘运行，启动时不弹出晾衣绳。
3. 截一张图，或在托盘中选择“添加图片”。图片保存后，晾衣绳自动展开确认至少 5 秒。

**使用 Snipaste：** 使用已经设置好的截图快捷键，完成截图或编辑后选择“钉在桌面”。晾衣绳只接收最终钉图，直接复制不上绳，编辑前的原图也不会额外加入。Snipaste 的桌面贴图同时保留，可自由拖动、缩放和对比。

**使用 Windows 截图：** Snipaste 未运行时，托盘截图入口自动切为“Windows 截图”。点击后选取区域，结果自动上绳，无需开启长期剪贴板接收。需要系统截图工具可用并将结果复制到剪贴板；若关闭了自动复制，在截图工具中点击复制即可。Esc 取消，未完成的接收在 2 分钟后结束。

Snipaste 启动后，托盘菜单切回它的截图入口，并读取当前快捷键设置。自动检测不到贴图目录时，可在托盘中选择 Snipaste 安装目录或 `history` 目录。

## 图片怎么用

| 操作 | 结果 |
| --- | --- |
| 左键单击 | 复制图片，并显示“已复制” |
| 右键单击 | 查看大图 |
| Shift + 右键 | 打开更多操作菜单；左键点击菜单外关闭 |
| 拖到另一张图片上 | 两张图片交换位置 |
| 拖出挂绳区域后松手 | 取下图片并清理对应缓存 |
| 拖拽时按 Esc | 取消拖拽，图片保留 |
| 上下拖动绳子 | 调整高度，松手后记住位置 |
| 长按图片 | 用画图编辑 |
| 菜单 → 另存为 | 保存一份需要长期保留的图片 |

## 排列与清理

新图片从**左侧**挂入，原有图片向右移动。最多暂存 **8 张**，满了再加入时，清理**当前最右侧**的一张及其晒图缓存。

没有手动交换位置时，最右侧就是最早加入的图片；拖拽排序会改变清理顺序。

拖给其他应用后，或在绳外没有接收目标的区域松手，同样会清理绳上的对应缓存。清空晾衣绳或从托盘退出会清理全部暂存图片；强制结束进程不会执行退出清理。

这些操作只清理晒图缓存，保留 Snipaste 桌面贴图、原文件和你另存的图片。需要长期保留的图片，请使用“另存为”。

## 展开与收起

- **没有图片：** 绳子和右侧小把手都隐藏。
- **自动收起后：** 单击屏幕右侧小把手即可展开，悬停 0.3 秒也可展开。
- **取用图片时：** 鼠标留在图片、绳子及附近缓冲区域内保持显示，离开 1.2 秒后收起。拖拽、调高度和打开菜单时保持显示。
- **主动展开后：** 通过快捷键或托盘展开会持续显示，再次主动收起才隐藏。

默认展开 / 收起键是 **Ctrl + Alt + T**，可在托盘中改为单键或组合键。它与截图快捷键分别设置。

## 托盘设置

- **开机启动：** 登录 Windows 后延迟 15 秒运行，先保持隐藏。移动程序后，手动运行一次以更新启动路径。
- **接收剪贴板图片：** 默认关闭，可开启以接收其他应用复制的图片；Snipaste 的直接复制仍不上绳。
- **监听文件夹：** 自动接收所选文件夹中新生成的图片。
- **清空晾衣绳 / 清理截图并退出：** 清理暂存图片，保留高度、快捷键等设置。

暂存图片和设置位于 `%LOCALAPPDATA%\ShaiTu`。没有截图工具时，仍可使用“添加图片”、剪贴板接收或监听文件夹，正常复制、查看、排序和另存。

<summary><strong>从源码构建</strong></summary>

项目使用 C#、WPF 和 .NET Framework 4.8。源码仓库不包含 exe，运行以下命令会生成 `dist/ShaiTu.exe`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

加 `-Test` 可运行自动检查。使用 `.\scripts\package-release.ps1 -Version 0.5.9` 打包便携版并生成 SHA256 校验文件。推送版本标签会触发 [Windows 自动构建与发布](https://github.com/weidaozhong/ShaiTu/actions)。
