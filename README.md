# 晒图 · ShaiTu

把截图挂到桌面的晾衣绳上，随手复制、查看和拖动排序。支持 Snipaste 钉图联动，也可使用 Windows 截图。Snipaste 的桌面贴图同时保留，方便自由拖动做对比。

**Windows 10 / 11 · .NET Framework 4.8 · 当前版本 0.5.8**

![晒图界面：三张示例图片由夹子挂在桌面晾衣绳上](./assets/readme/interface.png)

*程序实际渲染的界面，使用内置示例图片。*

## 从第一张截图开始

1. 从 [Releases 下载便携版 ZIP](https://github.com/weidaozhong/ShaiTu/releases/latest)，完整解压到固定文件夹，然后启动 `ShaiTu.exe`。保留同目录的 `ShaiTu.exe.config`，程序先在托盘运行。
2. 启动 Snipaste，使用你已经设置好的截图快捷键。
3. 完成截图或编辑后，选择**钉在桌面**。图片会复制到晾衣绳，保存成功后展开确认至少 5 秒。

直接在 Snipaste 中复制图片不会自动上绳；先编辑再钉图，只接收编辑后的最终版本。托盘里的“Snipaste 截图”也调用 Snipaste。

**没有 Snipaste：** 托盘中点击“Windows 截图”，选取区域后自动挂上绳并展开确认。此入口调用系统的 **Win + Shift + S**，无需开启长期剪贴板监听；仅接收本次 Windows 截图工具生成的图片。按 Esc 取消，未完成的接收在 2 分钟后结束。需要 Windows 自带的截图工具可用，且启用自动复制到剪贴板；关闭了自动复制时，在截图工具中点击复制即可接收。

## 图片怎么用

| 操作 | 结果 |
| --- | --- |
| 左键单击图片 | 复制图片，显示“已复制”提示 |
| 右键单击图片 | 查看大图 |
| Shift + 右键 | 打开更多操作菜单；左键点击菜单外关闭 |
| 拖到另一张图片上 | 两张图片交换位置 |
| 拖到挂绳区域外松手 | 取下图片并删除晒图的对应缓存 |
| 拖拽时按 Esc | 取消拖拽，图片保留 |
| 上下拖动绳子 | 调整整排高度，松手后记住位置 |
| 长按图片 | 用画图编辑晒图缓存 |
| 菜单 → 另存为 | 保存一份需要长期保留的图片 |

最多暂存 **8 张**，满了会淘汰最左边的一张。拖给其他应用后，或绳外松手处没有接收目标，同样会清理绳上的对应缓存。

## 什么时候展开和收起

- **没有图片：** 绳子、提示和右侧小把手全部隐藏。
- **自动收起后：** 屏幕右侧的小把手随绳子高度定位；单击立即展开，悬停 0.3 秒展开。
- **正在取用：** 鼠标停在图片、绳子及附近缓冲区域时保持显示；离开 1.2 秒再收起。拖拽、调高度和打开菜单时保持显示。
- **主动展开：** 按快捷键或从托盘展开后持续显示，再次主动收起才隐藏。

默认展开 / 收起键是 **Ctrl + Alt + T**。托盘 → **设置展开 / 收起快捷键**可改成单键或组合键，不会更改 Snipaste 的截图键。

## 桌面贴图与晾衣绳各自保留

Snipaste 桌面贴图可继续自由拖动、缩放和对比；晾衣绳保存的是独立副本。

| 操作 | 晾衣绳缓存 |
| --- | --- |
| 从绳上取下一张 | 删除对应图片 |
| 清空晾衣绳 / 从托盘退出 | 清空 |
| 强制结束晒图进程 | 不执行退出清理 |

上述操作均保留 Snipaste 贴图、原文件以及你另存的图片。Snipaste 的贴图和原文件由 Snipaste 自己管理。

已取下的图片，在当前连接期间不会因为同一贴图重复写入相同像素而重新挂回绳上。

## 托盘设置

- **开机启动：** 登录 Windows 后延迟 15 秒运行，先保持隐藏。手动打开不延迟；关闭开关即可取消自启动。
- **添加图片：** 手动把已有图片挂上绳。
- **接收剪贴板图片 / 监听文件夹：** 可选入口，默认以 Snipaste 钉图为主。Snipaste 的直接复制动作仍不自动接收。
- **选择 Snipaste 目录：** 自动检测失败时，选择安装目录或 `history` 目录。

自动接收依赖 Snipaste 写出的贴图 PNG 文件。程序只读取最终贴图，不导入 `.sp1` 截图历史，也不会关闭或隐藏 Snipaste 贴图。

## 换一台电脑使用

便携包不包含原电脑的个人设置、Snipaste 配置和截图缓存。新电脑首次运行使用默认设置；Snipaste 的截图快捷键由那台电脑的 Snipaste 自己管理，晒图只读取并显示，不修改它。

启动 Snipaste 后，晒图会从正在运行的程序位置和常见用户目录自动检测 `history`。特殊安装位置或自定义数据目录检测失败时，在托盘中选择 Snipaste 安装目录或 `history`，也可恢复自动检测。

没有 Snipaste 或尚未启动它时，托盘截图入口自动切为“Windows 截图”。Snipaste 启动后，再次打开托盘菜单会切回 Snipaste，使用当地设置好的截图键，不修改配置。

还可通过“添加图片”导入文件，开启“接收剪贴板图片”接收其他应用复制的图片，或配置监听文件夹。复制、预览、排序、另存、自启动和缓存清理均不依赖 Snipaste。Windows 截图后备入口使用系统组件；如果该组件被卸载或快捷键被其他工具替换，可继续手动添加图片。

<details>
<summary><strong>缓存位置与自启动细节</strong></summary>

截图暂存与设置位于 `%LOCALAPPDATA%\ShaiTu`。`captures.log` 记录新增图片的来源、尺寸和缓存文件名，随清空或退出删除。

自启动使用当前用户启动文件夹中的 `ShaiTu.lnk`。旧版已经开启的注册表启动项会迁移，避免重复启动；重新开启开关会修复 exe 路径。开关也识别 Windows 的禁用状态。

移动程序后，手动运行一次以更新已启用的自启动路径。程序已在运行时，重复的自动启动会静默退出。

## 从源码构建

项目使用 C#、WPF 和 .NET Framework 4.8。`src` 为源码，`dist` 为当前程序，`build.ps1` 为构建脚本。

源码仓库不包含 exe；本地构建后会生成 `dist/ShaiTu.exe`。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

加 `-Test` 可运行自动检查。

`.\scripts\package-release.ps1 -Version 0.5.8` 将构建结果打包为便携版 ZIP，并生成 SHA256 校验文件。推送 `v*` 标签会触发 [Windows 构建及发布](https://github.com/weidaozhong/ShaiTu/actions)，也可用现有标签手动触发。
